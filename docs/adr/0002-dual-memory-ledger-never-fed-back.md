# 双层记忆：客观账本永不喂回 Agent

Agent 能回忆的历史只有它自己写的主观日记（Diary）加上当前持仓与可用资金快照；平台维护的完整交易流水（客观账本 Ledger）仅供研究者复盘，永不进入 Agent 上下文。看起来像缺陷（「为什么不把交易历史给它？」），实际是刻意设计：真实散户的记忆是有偏的——选择性遗忘、归因偏差——把准确流水喂回去等于替 Agent 消除记忆偏差，给韭菜装上机构级复盘系统，直接污染 [0001](./0001-emergent-behavior-not-scripted.md) 要观察的涌现行为。被拒绝的替代方案（完整历史喂回）行为更稳定可追溯，但记忆偏差这条观察线会整体消失。

边界：当前持仓和可用资金必须准确喂给 Agent，因为真实散户打开券商 App 也看得到这些数字——这不属于记忆，属于环境。
