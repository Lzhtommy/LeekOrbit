# 韭菜行为必须涌现，不允许剧本注入

平台的目的是行为金融学观察实验：验证一个被限制在散户级信息饮食中、承受真实 A 股规则摩擦（T+1、涨跌停、税费）的 LLM Agent 会不会自发涌现追涨杀跌、处置效应等韭菜行为。因此人设（Persona）只允许描述背景（年龄、职业、本金、动机、作息），严禁写入任何行为指令（「你会追热点」「你听消息炒股」）。被拒绝的替代方案是直接写韭菜行为剧本——那样行为更稳定、内容感更强，但实验就退化为「验证 LLM 会演戏」，观察结果失去全部价值。这条约束贯穿所有 prompt 设计，之后任何人觉得「Agent 不够韭菜、加一句人设就好了」都是在破坏实验——先改信息饮食或人设背景，不许改行为。

## Consequences

- 实验可能「失败」：Agent 可能涌现出谨慎理性的行为而非韭菜行为。这本身是有效的实验结果，不是 bug。
- 模型选择是实验变量：不同模型默认人格不同，换模型即换被试。
