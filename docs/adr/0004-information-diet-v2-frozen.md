# 信息饮食 v2：补齐题材叙事与快讯，行情三源互备，随后冻结

被试 leek-01 于 2026-07-14 上午归零重开；当日下午扩充信息饮食并定义**人生第一周（至 2026-07-18 收盘）为调试期**，此后信息饮食冻结——观察期内再改信息环境即视为更换实验条件（与 ADR-0003 的模型锁定同级）。本次扩充：① 涨停池/连板梯队/所属行业（东财 push2ex）进盘中/午休/收盘/晚间信息流——题材叙事是 A 股散户决策主粮，此前缺失；② 财联社快讯（官方 v1 API+本地签名）进盘前/午休/晚间/周末——散户刷手机的宏观叙事入口；③ 行情主源切换为腾讯财经（不封 IP、含权威涨跌停价），东财、新浪降为备源，且所有东财请求经全局串行限流（≥1.2s+抖动）——东财对单 IP 有风控，此前的快速重试模式恰在触发它。端点实现移植自 simonlin1212/a-stock-data（V3.4.0，逐段审读后按需移植，未整包引入）；该项目的研报/筹码/龙虎榜等机构级端点**明确排除**——韭菜不看研报（ADR-0001 的信息饮食纪律）。

## Consequences

- 快讯与涨停池属「调味料」：拿不到时信息流静默省略对应板块（区别于行情/持仓这类「主粮」的显式「加载失败」标注）——缺调味料不值得让被试知道。
- 盘中信息流变长，haiku 层单次唤醒成本略升；仍远低于预算。
- 2026-07-18 之后若要再动信息饮食，等于开新被试实验。
