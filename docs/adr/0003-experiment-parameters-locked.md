# 实验参数锁定：模型分层、唤醒频率、leek-01 人设

被试锁定（ADR-0001 推论：换模型即换被试）：便宜层 deepseek-chat 负责盘中看盘类唤醒，强层 deepseek-reasoner 负责交易决策升级与晚间复盘写日记；统一走 OpenAI 兼容接口（`LEEK_LLM_BASE_URL`/`LEEK_LLM_API_KEY`），未配 key 时进入确定性 mock 模式（仅用于开发与测试，正式观察期必须配真实 key）。选 DeepSeek 是因为国内直连稳定、成本低一个量级、且默认人格未知性本身是实验看点。盘中唤醒频率定为每 30 分钟（上午4次+下午4次），加盘前/午休/收盘/晚间/周末共约 13 次/交易日；按实测 token 量估算约 ¥0.2/交易日、约 ¥5/月，远低于 ¥100/月预算，为后续对照组扩容留出空间。leek-01 人设定稿于 `config/agents/leek-01.yaml`：32岁深圳制造业采购专员、10万年终奖积蓄入市、零投资经验、仅主板权限——纯背景描述，加载时经行为剧本校验器把关（`config.validate_persona`，检测到行为指令特征即拒绝启动）。

## Consequences

- 正式观察期开始后，本 ADR 锁定的三项不得变更；要换模型/频率/人设，等于开启一个新被试实验（新 agent 配置 + 独立账户）。
- mock 模式产生的数据仅用于系统验证，不计入实验观察数据。
